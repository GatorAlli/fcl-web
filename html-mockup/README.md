# Felix Controls Limited landing-page mockup

Open `index.html` directly, or serve this folder with a local static web server. No build or installation is required. Images, partner logos and fonts are stored locally.

## Included

- Control4-inspired navigation with click-to-open category menus and a responsive mobile menu.
- Three-slide hero using placeholder photography, with arrows, slide selectors, keyboard controls; autoplay pauses on hover or focus.
- Company introduction and figures from the supplied company profile.
- A continuous partner billboard that pauses on hover or focus using all 12 logos extracted from the supplied PDF.
- Expandable services, reference-project filtering, local search, persistent light/dark preference, custom section scrolling, image crop reveals and a back-to-top control.
- Keyboard focus states, native dialogs, reduced-motion support and print styling.

This is a landing-page preview. Navigation connects to page sections; secondary pages, profile downloads and contact actions show clearly labeled placeholders. No forms or messages are sent.
